# La Cabane Mauricienne website (Next.js)

Edit all texts in `app/page.js` (phone, address, dishes, links) and the photos in `public/dishes/`.

## Run locally
    npm install
    npm run dev

## Deploy on Vercel
1. Put this folder in a GitHub repository.
2. On vercel.com choose "Add New Project", import the repository, click Deploy.
3. Later, add the restaurant's own domain in Project Settings, Domains.
